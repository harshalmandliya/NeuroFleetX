## Authentication

All API endpoints require authentication via JWT tokens. Tokens should be included in the Authorization header as a Bearer token.

```
Authorization: Bearer <your-jwt-token>
```

## Ride Requests

### Get All Ride Requests

**GET** `/api/rides`

Returns a list of all ride requests.

#### Response
```json
[
  {
    "id": 1,
    "originLat": 40.7128,
    "originLng": -74.0060,
    "destLat": 40.7589,
    "destLng": -73.9851,
    "trafficIndex": 0.7,
    "weather": "sunny",
    "assignedTaxiId": 1,
    "eta": 12.5,
    "status": "PENDING",
    "timestamp": "2023-05-15T10:30:00"
  }
]
```

### Create Ride Request

**POST** `/api/rides`

Creates a new ride request. Note that trafficIndex and weather are auto-generated by the system.

#### Request Body
```json
{
  "originLat": 40.7128,
  "originLng": -74.0060,
  "destLat": 40.7589,
  "destLng": -73.9851,
  "eta": 12.5,
  "status": "PENDING"
}
```

#### Response
```json
{
  "id": 1,
  "originLat": 40.7128,
  "originLng": -74.0060,
  "destLat": 40.7589,
  "destLng": -73.9851,
  "trafficIndex": 0.7,
  "weather": "sunny",
  "assignedTaxiId": null,
  "eta": 12.5,
  "status": "PENDING",
  "timestamp": "2023-05-15T10:30:00"
}
```

### Update Ride Request

**PUT** `/api/rides/{id}`

Updates an existing ride request.

#### Request Body
```json
{
  "originLat": 40.7128,
  "originLng": -74.0060,
  "destLat": 40.7589,
  "destLng": -73.9851,
  "eta": 15.0,
  "status": "ASSIGNED",
  "assignedTaxiId": 1
}
```

#### Response
```json
{
  "id": 1,
  "originLat": 40.7128,
  "originLng": -74.0060,
  "destLat": 40.7589,
  "destLng": -73.9851,
  "trafficIndex": 0.7,
  "weather": "sunny",
  "assignedTaxiId": 1,
  "eta": 15.0,
  "status": "ASSIGNED",
  "timestamp": "2023-05-15T10:30:00"
}
```

### Delete Ride Request

**DELETE** `/api/rides/{id}`

Deletes a ride request by ID.

#### Response
```
204 No Content
```

## Taxi Management

### Get All Taxis

**GET** `/api/taxis`

Returns a list of all taxis.

#### Response
```json
[
  {
    "id": 1,
    "name": "Taxi 1",
    "latitude": 40.7128,
    "longitude": -74.0060,
    "batteryLevel": 85,
    "status": "AVAILABLE"
  }
]
```

### Create Taxi

**POST** `/api/taxis`

Creates a new taxi.

#### Request Body
```json
{
  "name": "Taxi 6",
  "latitude": 40.7505,
  "longitude": -73.9934,
  "batteryLevel": 90,
  "status": "AVAILABLE"
}
```

#### Response
```json
{
  "id": 6,
  "name": "Taxi 6",
  "latitude": 40.7505,
  "longitude": -73.9934,
  "batteryLevel": 90,
  "status": "AVAILABLE"
}
```

### Update Taxi

**PUT** `/api/taxis/{id}`

Updates an existing taxi.

#### Request Body
```json
{
  "name": "Taxi 1 Updated",
  "latitude": 40.7505,
  "longitude": -73.9934,
  "batteryLevel": 75,
  "status": "CHARGING"
}
```

#### Response
```json
{
  "id": 1,
  "name": "Taxi 1 Updated",
  "latitude": 40.7505,
  "longitude": -73.9934,
  "batteryLevel": 75,
  "status": "CHARGING"
}
```

### Delete Taxi

**DELETE** `/api/taxis/{id}`

Deletes a taxi by ID.

#### Response
```
204 No Content
```

## Driver Functions

### Assign Taxi to Ride

**POST** `/api/dispatch/assign/{rideId}`

Assigns the nearest available taxi to a ride request.

#### Response
```json
{
  "taxiId": 1,
  "eta": 12.5
}
```

## Prediction Service

### Predict ETA

**POST** `/api/predict`

Predicts the estimated time of arrival for a ride. Note that trafficIndex and weather are used for prediction but are auto-generated for actual ride requests.

#### Request Body
```json
{
  "originLat": 40.7128,
  "originLng": -74.0060,
  "destLat": 40.7589,
  "destLng": -73.9851,
  "trafficIndex": 0.7,
  "weather": "sunny"
}
```

#### Response
```json
{
  "predictedETA": 12.5
}
```
